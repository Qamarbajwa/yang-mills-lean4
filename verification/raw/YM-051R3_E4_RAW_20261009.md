### 5. Signed Orientation Determinant vs. Absolute Integration Jacobian
- **First-Principles Lie Theory & Differential Geometry Audit:**
  - Let $b = (x, y)$ be an oriented link directed from parent $x$ to child $y$.
  - The gauge-transformed link is $U^h(b) = h_x U(b) h_y^{-1}$.
  - Under infinitesimal gauge transformations $h_x = \exp(\xi_x)$ and $h_y = \exp(\xi_y)$ with $\xi_x, \xi_y \in \mathfrak{su}(2)$, the first variation around background $V_0(b)$ is:
    $$\delta U^h(b) = \xi_x V_0(b) - V_0(b) \xi_y.$$
  - Expressing the variation in left Lie algebra coordinates:
    $$(D_{V_0} \xi)(b) = (\delta U^h(b)) V_0(b)^{-1} = \xi_x - V_0(b) \xi_y V_0(b)^{-1} = \xi_x - \operatorname{Ad}_{V_0(b)} \xi_y.$$
  - For a rooted tree with root gauge-fixing condition $\xi_{x_0} = 0$:
    - For edge $b_1 = (x_0, x_1)$, $\xi_{x_0} = 0$, so:
      $$(D_{V_0} \xi)(b_1) = - \operatorname{Ad}_{V_0(b_1)} \xi_{x_1}.$$
    - The directional derivative operator with respect to child variable $\xi_{x_1}$ is $- \operatorname{Ad}_{V_0(b_1)}$.
  - Determinant evaluation on $\mathfrak{su}(2)$:
    - Real dimension of Lie algebra $\mathfrak{su}(2)$ is $n = 3$.
    - $\operatorname{Ad}_{V_0} \in SO(3)$, hence $\det(\operatorname{Ad}_{V_0}) = +1$.
    - For any $n \times n$ matrix $M$, $\det(-M) = (-1)^n \det(M)$.
    - For $n = 3$:
      $$\det(- \operatorname{Ad}_{V_0(b_1)}) = (-1)^3 \det(\operatorname{Ad}_{V_0(b_1)}) = (-1) \cdot (+1) = -1.$$
  - Tree orientation dependency:
    - For a tree with $k$ child edges directed away from the root, the signed block determinant is:
      $$\det(D_{V_0}) = (-1)^{3k} = (-1)^k.$$
    - For odd $k$ (such as $k=1$ or $k=3$), $\det(D_{V_0}) = -1$; for even $k$, $\det(D_{V_0}) = +1$.
    - If edge orientations are reversed (child to parent), the sign flips.
    - If basis ordering or variable ordering is permuted, the sign can also change.
    - Therefore, the claim in YM-051R2 that $\det(D_{V_0}) = +1$ universally was mathematically erroneous.
  - **Absolute Integration Jacobian:**

      $$|\det(D_{V_0})| = |(-1)^k| = 1.$$
    - The absolute integration Jacobian is universally, robustly, and orientation-independently equal to $1$.
